# เว็บไซต์งานวิชาการ โรงเรียนหนองหานวิทยา

Next.js 15 + Supabase (ฐานข้อมูล/ล็อกอิน/เก็บไฟล์) deploy บน Vercel
รูปแบบ **C — ครบวงจร**: ส่วนสาธารณะ + ส่วนครู (ล็อกอิน) + หน้าจัดการเนื้อหา `/admin`

## สิ่งที่มีในเว็บ

| ส่วน | เส้นทาง |
|---|---|
| หน้าแรก (สไลด์ภาพ ทางลัดบริการ ข่าว กำหนดการ เอกสารล่าสุด แกลเลอรี) | `/` |
| ข่าวประชาสัมพันธ์ (กรองตามหมวด) | `/news` |
| หลักสูตร / ทะเบียนวัดผล / การเรียนการสอน / นิเทศและประกันคุณภาพ / พัฒนาผู้เรียน | `/curriculum` `/registrar` `/teaching` `/quality` `/student-development` |
| คลังเอกสาร (ค้นหา, หมวด, ปีการศึกษา, เฉพาะครู) | `/documents` |
| ปฏิทิน (ตาราง + ฝัง Google Calendar) | `/calendar` |
| ระบบบริการออนไลน์ (สาธารณะ / เฉพาะครู) | `/services` |
| ผลงานและนวัตกรรม | `/achievements` |
| เกี่ยวกับโรงเรียน | `/about` |
| ล็อกอินครู | `/login` |
| จัดการเนื้อหา (editor/admin) | `/admin` |

ข้อมูลที่ดึงจากเว็บโรงเรียนแล้ว: ชื่อ ที่อยู่ เบอร์โทร ผู้บริหาร ประวัติ วิสัยทัศน์/พันธกิจ คำขวัญ ลิงก์ระบบ SGS/การเงิน รายงาน SAR 2563–2567 ภาพกิจกรรม/โลโก้ (โหลดตรงจากเซิร์ฟเวอร์ภาพของโรงเรียน)
ข้อมูลที่ **ยังไม่มี** (เติมภายหลัง): เบอร์/อีเมล/LINE/Facebook ของฝ่ายวิชาการ, สีประจำโรงเรียนและความหมายตราสัญลักษณ์, ปฏิทินจริง, เอกสารและข่าวของฝ่ายวิชาการ → เติมที่ `/admin` (ข้อมูลติดต่อที่ `/admin/settings`)

## ขั้นตอนติดตั้ง (ใช้อีเมลของฝ่ายวิชาการ)

ทำทุกขั้นตอนด้วยบัญชีอีเมลกลางของฝ่ายวิชาการ ไม่ใช่อีเมลส่วนตัว เพื่อให้ฝ่ายถือกรรมสิทธิ์ระบบ

### 1) Supabase
1. สมัคร/ล็อกอิน <https://supabase.com> ด้วยอีเมลฝ่ายวิชาการ → **New project** (ภูมิภาค Singapore)
2. **SQL Editor** → วางเนื้อหาไฟล์ `supabase/schema.sql` ทั้งไฟล์ → **Run**
   (สร้างตาราง สิทธิ์ RLS ที่เก็บไฟล์ `academic-docs` และข้อมูลเริ่มต้น)
3. **Project Settings → API** คัดลอก `Project URL` และ `anon / publishable key`
4. **Authentication → Providers → Email** เปิดใช้งาน; ปิด “Allow new users to sign up” หากไม่ต้องการให้คนทั่วไปสมัครเอง แล้วสร้างบัญชีครูที่ **Authentication → Users → Add user**
5. สร้างบัญชีแอดมินคนแรก (ใช้อีเมลฝ่ายวิชาการ) แล้วตั้งสิทธิ์ใน SQL Editor:
   ```sql
   update public.profiles set role = 'admin' where email = 'อีเมลฝ่ายวิชาการ@...';
   ```

สิทธิ์ (`profiles.role`): `guest` (ล็อกอินได้แต่ยังไม่เห็นเนื้อหาครู) · `teacher` (เห็นเอกสาร/บริการเฉพาะครู) · `editor` (เพิ่ม/ลบเนื้อหา) · `admin`
อีเมลโดเมน `@nonghanwit.ac.th` ได้สิทธิ์ `teacher` อัตโนมัติ — อีเมลอื่นเริ่มเป็น `guest`

### 2) รันในเครื่อง (ไม่บังคับ)
```bash
cp .env.example .env.local   # ใส่ค่าจาก Supabase
npm install
npm run dev                  # http://localhost:3000
```
ถ้ายังไม่ใส่ `.env.local` เว็บยังเปิดได้ด้วยข้อมูลโรงเรียนตั้งต้น (ส่วนข่าว/เอกสารจะว่างจนกว่าจะเชื่อม Supabase)

### 3) Vercel
1. สมัคร/ล็อกอิน <https://vercel.com> ด้วยอีเมลฝ่ายวิชาการ
2. อัปโหลดโค้ดนี้ขึ้น GitHub (บัญชีฝ่ายวิชาการ) → Vercel **Add New → Project** → เลือก repo
3. ใส่ Environment Variables: `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`, `NEXT_PUBLIC_ACADEMIC_EMAIL` (ไม่บังคับ)
4. **Deploy** — ได้ลิงก์ `*.vercel.app` (ผูกโดเมนของโรงเรียนภายหลังที่ Settings → Domains)
5. กลับไป Supabase → **Authentication → URL Configuration** ใส่ Site URL เป็นลิงก์ Vercel

หรือใช้ CLI: `npm i -g vercel && vercel --prod`

## การเพิ่มข้อมูลภายหลัง
- ข่าว เอกสาร ปฏิทิน ลิงก์บริการ ผลงาน → `/admin/<ตาราง>` (เอกสารอัปโหลดไฟล์ได้ หรือวางลิงก์ Google Drive)
- ข้อมูลติดต่อฝ่ายวิชาการ ปีการศึกษา/ภาคเรียน ลิงก์ฝัง Google Calendar → `/admin/settings`
- หัวข้อย่อยของแต่ละหมวด → `lib/sections.ts` · ข้อมูล/ภาพโรงเรียน → `lib/school.ts` · สีเว็บ → ตัวแปร `:root` ใน `app/globals.css`

## ข้อควรระวัง
- **ไม่เก็บผลการเรียนรายบุคคล** ในเว็บนี้ — ใช้ระบบ SGS ของ สพฐ. ผ่านหน้า “ระบบบริการออนไลน์”
- bucket `academic-docs` เป็น public (ใครมีลิงก์เปิดได้) เอกสารที่อ่อนไหวควรใช้ลิงก์ Google Drive ที่จำกัดสิทธิ์เฉพาะ @nonghanwit.ac.th
- ภาพบนเว็บโหลดตรงจากเซิร์ฟเวอร์ภาพของโรงเรียน (thai.ac) หากลิงก์เสียให้อัปโหลดภาพของฝ่ายเอง แล้วแก้ใน `lib/school.ts`
- หน้าแอดมินรองรับ “เพิ่ม” และ “ลบ” (ยังไม่มีปุ่มแก้ไขรายการเดิม — ลบแล้วเพิ่มใหม่ หรือแก้ใน Supabase Table Editor)
